Decisions this shell settles (§ 7.6)

  • State shapes: idle = hollow ring, running = spinning arc, waiting = filled disc with a pulsing halo (loudest), exited = a flat dash. Shape carries it; colour only reinforces.
  • Worktree glyph is the branch mark at rest and takes over the strongest agent state — one slot, never two.
  • Segmented control: four segments don't fit at sidebar width, so unselected ones drop their label below a 420px container. The selected label always shows.
  • Indentation steps 18px: worktree 8 → agent 30 → subagent 48 (rail-indented under the card).
  • Subagent history: a left rail, a Past delegations label, and outcome glyphs (✓ ✕) — never the live dot vocabulary.
  • Markers: pills name which worktree (main, here); outlined badges say how it is (locked, missing, prunable). Confidence is a dim ~; external scope is a labelled chip.
  • Notices carry the failing source and its verbatim reason in mono, and sit on the scope they concern.
  • Narrow rule (deviation): the spec's truncation order is preview then title, but a preview clipped to one or two characters reads as noise — below a 380px panel the preview cell collapses instead, and the title takes the space. The age column and the leading icons still never move.
