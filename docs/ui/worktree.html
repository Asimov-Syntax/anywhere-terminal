What changed, and why

  • Worktrees is the rail. One toggle, Worktrees | Sessions, replaces four equal segments; Recent / Agent / Folder survive as Sessions' own grouping, one level down. The panel now answers "what is running where" before "what did I run".
  • Scope lives in the tab bar. Selecting a worktree filters panes and puts a chip with its name at the head of the tab bar; All is the only way out, so the filter can never be invisible. Default scope is main.
  • Inspector is a drawer, not a replacement. Selecting a row opens a detail region under the tree (capped at ~52% of the panel) instead of swapping the body. In a 300px column, replacing the body makes selection destructive: you lose the list you were comparing against and need a back button to return. The drawer keeps the rail scannable while one worktree is read in full — and it is where the path lives, since rows never show one.
  • Agent rows are two lines — identity + age above, last message below. That is the line users actually read (Approve the git worktree add?), and it no longer competes with a model chip for width.
  • Idle tail folded. Worktrees with agents sort first and render in full; agentless ones are a dim single line, and from four upward they collapse under N idle worktrees.

State table

  • Shape, not colour, carries the state: spinning arc, static broken arc, filled disc, check, dim ring, struck ring. Waiting is the only strong animation, because it is the only state that needs a person.
  • working (unconfirmed) is a separate state, not a footnote on working: activity inferred from output with no recent confirmation stands still and says how long it has been quiet.
  • Reduced motion turns every animation off and leaves each glyph legible as a static shape.

Markers

  • open replaces here — several worktrees can be workspace folders at once, and here implied one was where you are.
  • main, locked, missing and prunable are icon badges with tooltips; only open keeps a word, since it has no unambiguous glyph.

Open for your call

  • Whether the scope chip should also appear in the panel header (it currently only lives on the tab bar).
  • Whether selecting a worktree should scope the terminal immediately, or only on double-click / explicit Focus.
  • Idle-tail threshold: four feels right for a 300px column; higher if your repos usually carry many idle worktrees.
  • Create's destination default: …/.claude/worktrees/<name> here, versus the shipped sibling-directory default …/<repo>-<branch>.
